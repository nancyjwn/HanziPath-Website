# Taste Skill: Anti-AI-Slop & High-Agency Art Direction

Inspired by `Leonxlnx/taste-skill`, this skill enforces authentic, bespoke frontend design that looks handcrafted by world-class designers rather than generated by generic AI templates.

## 1. The Anti-AI-Slop Manifesto

AI coding assistants frequently suffer from predictable, cookie-cutter design habits ("AI Slop"). Never use these defaults:
- **No Cliché Gradients:** Avoid generic indigo-to-purple or cyan-to-magenta linear gradient text or backgrounds.
- **No Uniform 3-Column Feature Cards:** Avoid three identical rounded cards with a small colored SVG icon in a circular box followed by a bold header and 2 lines of generic marketing copy.
- **No Floating Generic Glowing Blobs:** Avoid random, disconnected blurry purple circles positioned aimlessly in background corners.
- **No Monotone Gray Shadows:** Avoid harsh, muddy `box-shadow: 0 4px 6px rgba(0,0,0,0.1)`. Use tinted, soft ambient shadows matching the underlying surface (e.g. `rgba(41,39,35,0.04)`).
- **No Sterile Eyebrows:** Avoid generic pill badges like `★ ALL-IN-ONE SOLUTION ★` or `A LITTLE PRACTICE EVERY DAY` enclosed in generic capsule borders. Replace with authentic cultural accents (e.g., traditional seal stamps, minimalist hairline rules, elegant typographic tags).

## 2. Intentional Art Direction Workflow

Before implementing any frontend component or page, execute this 3-step pipeline:

### Step 1: Inventory & Domain Brief
Catalog the unique essence of the project:
- **Domain:** Classical & Modern Chinese Language Learning (Mandarin).
- **Core Vernacular:** Ink wash (*shuimò*), Xuan paper, cinnabar seal stamps (*yìnzhāng*), Tian Zi Ge practice grids, bamboo foliage silhouettes, Leitner spaced repetition flashcards.
- **Audience:** Serious language learners who value beauty, scholarship, tactile writing practice, and modern speed.

### Step 2: Bespoke Design System Tokens
Bind the visual language to a disciplined 4–5 color palette:
- **Base Surface:** Rice/Xuan Paper `#FBF9F5` / `#FAF6F0`
- **Ink Primary:** Charcoal Ink `#292723` / `#1F1E1B`
- **Cultural Accent:** Cinnabar Red `#9E2A2B` / `#B83A30`
- **Secondary Tone:** Warm Sand `#EDE5D8` / `#DCD2C3`
- **Jade / Success:** Celadon Jade `#2E7D5B`
- **Typography:** Classical serif display (Playfair / Noto Serif SC) paired with modern, legible neo-grotesque sans-serif for UI labels and pinyin.

### Step 3: Tunable Style Dials
- **`DESIGN_VARIANCE` [High]:** Every section must have distinct spatial personality (e.g., seamless folder tabs in HSK explore, scattered calligraphy practice grids in Daily Words, floating cursor badges in Footer).
- **`VISUAL_DENSITY` [Restrained / Breathable]:** Generous whitespace (`py-20 sm:py-28`, `gap-8 lg:gap-10`) that lets typography breathe.
- **`MOTION_INTENSITY` [Subtle & Tactile]:** Quick, organic spring physics (`stiffness: 350, damping: 25`) with tactile scale presses (`active:scale-[0.98]`).

## 3. Strict House Rules

1. **Max 2-Line Headlines:** Headlines must be punchy, rhythmic, and wrap within 2 lines on desktop. Never leave orphan words.
2. **Authentic Texture over Flat Plastic:** Use delicate rice paper dot matrices, calligraphy grid lines, or subtle ink mist gradients instead of flat monotonous grey fills.
3. **Intentional Hierarchy:** Every viewport must have one undeniable visual focal point, followed by calm secondary and tertiary elements.
4. **Responsive Integrity:** Test and guarantee seamless visual balance across viewports: Desktop (1280px+), Tablet (768px), and Mobile (375px).
